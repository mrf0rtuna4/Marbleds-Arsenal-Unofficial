# Marbled's Arsenal (Unofficial Port)

This repository contains an **unofficial port** of **Marbled's Arsenal**, originally created by **MarbledNull**.

The original project is a core mod for Minecraft Forge 1.16.5–1.20.1 and is required by some of MarbledNull's mods. It can also be used as a standalone mod with its own features.

## Support

This fork is **not maintained or supported by MarbledNull**.

Please **do not contact the original author** regarding bugs, crashes, feature requests, or any other issues related to this port.

If you encounter a problem with this fork, please open an issue in **this repository**.

Look at https://github.com/mrf0rtuna4/Marbleds-Arsenal-Unofficial/issues

## Original Project

The original project is available on:

* CurseForge: https://www.curseforge.com/minecraft/mc-mods/marbleds-arsenal
* Modrinth: https://modrinth.com/mod/marbleds-arsenal
